# 情侣小窝 - 产品介绍

> 一款专为情侣打造的微信小程序，记录恋爱中的点点滴滴，让甜蜜时刻永不褪色。

---

## 产品概述

**情侣小窝**（Our Nest）是一款基于微信小程序的情侣专属空间。在这里，情侣双方可以共同记录生活瞬间、分享照片、书写日志，打造属于两个人的私密小天地。

## 核心功能

### 📝 日记/动态发布
双方都可以在小窝中发布动态、记录心情和日常点滴，支持图文混排，让每一条记录都充满温度。

### 📸 共享相册
创建专属相册，上传照片到共享空间。支持按相册分类管理，方便回顾每一个美好瞬间。

### 💕 纪念日倒数
设置恋爱纪念日，首页自动显示已在一起的天数，让每一天都充满仪式感。

### 🔐 权限管理
精细化的用户权限设置，支持游客模式和成员模式：
- **游客模式**：只能查看最近 20 条记录
- **成员模式**：可以发布内容、创建相册、查看全部数据

### 📱 分享朋友圈
支持将动态分享到微信朋友圈，与好友分享幸福时刻。

## 技术架构

| 层级 | 技术 |
|------|------|
| 前端框架 | 微信小程序原生 + WeUI |
| 后端服务 | 微信云开发（云函数） |
| 数据库 | 云开发数据库（NoSQL） |
| 存储 | 云开发存储服务 |
| 语言 | JavaScript / Node.js |

## 技术特性

- **零服务器成本**：基于微信云开发，无需自行搭建服务器
- **自动扩容**：云函数按需执行，自动应对流量高峰
- **数据安全**：基于微信账号体系，数据隔离有保障
- **快速部署**：克隆代码 → 配置环境 → 一键上传，三步完成

## 适用场景

- 情侣日常记录与互动
- 恋爱纪念日倒数
- 共同照片管理与回顾
- 小圈子私密社交
