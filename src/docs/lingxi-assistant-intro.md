# 灵犀 AI 智能助手 - 产品介绍

> 心有灵犀一点通 — 面向所有人的 AI 智能助手，让 AI 洞察你的意图，一触即通。

---

## 产品概述

**灵犀**（LingXi）是一款面向所有人的 AI 智能助手，通过自然语言和语音即可完成工作。命名来自「心有灵犀一点通」—— AI 洞察用户意图，一触即通。

灵犀支持**桌面端**、**VS Code 扩展**、**CLI 终端**三种产品形态，覆盖开发者、办公人员、项目经理、数据分析师等不同用户群体。

## 产品形态

| 形态 | 目标用户 | 技术方案 |
|------|----------|----------|
| **桌面端** | 所有用户 | Electron + React 19 + Tailwind CSS |
| **CLI 终端** | 开发者、运维、CI/CD | Node.js REPL |
| **VS Code 扩展** | 开发者 | VS Code Extension API + Webview |

## 核心功能

### 🖥️ 多端覆盖
桌面端（Windows/Mac/Linux）、VS Code 扩展、CLI 终端三种交互方式，无缝适配各类工作场景。

### 🧠 多模型接入
支持 DeepSeek、OpenAI、Anthropic、Gemini、通义千问、Groq、Mistral 等 7 家主流 AI 厂商，灵活切换不同模型满足不同任务需求。

### 🛠️ 丰富工具集
内置 35+ 工具，涵盖文件读写、代码搜索与编辑、Office 文档处理、图像识别与生成、语音合成与识别、Git 操作、SSH 远程连接、浏览器自动化等全方位能力。

### 🎤 语音对话
支持连续语音对话模式，自动语音识别与播报，解放双手。

### 🔐 安全可控
- **四层权限模型**：normal / auto / strict / fullAccess，自由控制 AI 的操作权限
- **本地优先处理**：数据不上传云端，保障信息安全
- **危险命令拦截**：自动识别并阻止 `rm -rf /` 等危险操作
- **API Key 加密存储**：桌面端使用 Electron safeStorage 加密

### ⚡ 流式响应
实时 Markdown 渲染，工具调用过程可视化，思考过程透明展示。

### 🧩 智能调度
- **Agent Loop**：自主执行"思考→行动→观察"循环
- **子 Agent 系统**：并行执行多任务，默认并发 16 个
- **Skill 系统**：13 个内置 Skill（代码生成、代码审查、Bug 修复、文档生成等），按需自动激活

### 🧩 扩展生态
- **MCP 协议集成**：开放 Model Context Protocol，连接外部工具
- **自定义 Skills**：支持项目级和用户级自定义 Skill
- **Hooks 系统**：事件钩子机制，自动化工作流
