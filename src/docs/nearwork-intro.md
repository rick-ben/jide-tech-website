## 产品概述

**NearWork** 是一款装在自己电脑上的多模型 AI 智能体。说一句话，它会读文件、跑命令、查网页、写文档、操作本机应用，把需求直接变成可交付的结果。

名字说的就是它的位置：任务被拆解、分派、执行、交付，各自归到该在的环节；你不再被搬运信息的杂务占满，回到做决定的位置。

配置、会话、技能与知识库都保存在本机，**只有发给所选模型的请求会离开电脑**。

## 产品形态

| 形态 | 适合谁 | 说明 |
|------|--------|------|
| **桌面端** | 所有人 | Windows / macOS / Linux，完整桌面体验 |
| **命令行** | 开发者、运维 | 支持管道与脚本集成，适合批量任务 |
| **VS Code 扩展** | 开发者 | 在编辑器里直接改代码、审查、重构 |
| **网页对话** | 临时使用 | 浏览器打开即用，不用安装 |

## 能做什么

- **会议录音整理成纪要**：结论、分歧、待办（含负责人和时间），一次输出
- **整理本地文件**：扫描目录，找出超过 5MB 的图片压缩到 1MB 以内，原文件自动备份
- **读懂陌生项目**：读 README 与依赖配置，告诉你本地怎么跑、缺什么
- **资料汇总**：联网查政策与行业变化，按可信度排序后给出简报
- **替你操作电脑**：看屏幕、点鼠标、敲键盘，完成填表、点按、截图这类跨应用重复劳动
- **定时任务**：到点自动执行，无人值守

执行过程是透明的：先想、再调工具、看结果、继续，直到交付。涉及写文件、跑命令这类动作时会先问你。

## 模型接入

NearWork 不自建模型，而是做一层「模型接入 + 任务执行」的壳：用哪家、哪个型号、走官方额度还是自己的 Key，都在设置里决定。

内置 **16 家供应商**，全部通过 OpenAI、Anthropic、Gemini 三种主流协议访问：

| 地区 | 供应商 |
|------|--------|
| 中国 | DeepSeek、通义千问、Kimi、智谱 GLM、豆包、MiniMax、文心一言、腾讯混元、阶跃星辰、小米 MiMo |
| 美国 | OpenAI、Anthropic、Gemini、xAI Grok、Groq |
| 欧洲 | Mistral |

只要对方的接口兼容这三种协议之一，即使不在列表里也能手动接入。

### 七个模型槽位

不把所有事情压给一个模型，而是按用途拆成七个槽位，各自填模型：

| 槽位 | 用在什么地方 |
|------|--------------|
| 极速 | 日常问答与改写，追求快和便宜 |
| 思考 | 复杂推理，方案设计、疑难 bug |
| 视觉 | 读截图、图表、扫描件 |
| 图像编辑 | 生成与修改图片 |
| 语音生成 | 文字转语音、朗读回复 |
| 语音识别 | 语音输入、录音转写 |
| 向量嵌入 | 记忆与知识库的语义检索 |

聊天时只需要关心「极速 / 思考」两个；其余槽位由对应功能自动取用。某个槽位空着，那项能力就暂不可用，不会悄悄换成别的模型。

### 官方额度与自带 Key

| 方式 | 适合 |
|------|------|
| 官方额度 | 想开箱即用，按订阅套餐计费，免费版自带周期性额度 |
| 自带 API Key | 已有供应商账号，请求直连所选供应商，费用由对方结算 |

两条路随时可切换，同一账号下不同会话也能用不同来源。自带 Key 不替代登录。

## 工具与技能

内置 **75 个工具**，覆盖从读一个文件到操控桌面应用的完整链路：

| 能力 | 举例 |
|------|------|
| 文件与代码 | 按行编辑、批量替换、改动前看差异、全文检索 |
| 命令与进程 | 执行命令，长驻任务可启动、观察、收尾 |
| 网页与网络 | 联网搜索、抓取正文、直调 API |
| 文档与表格 | CSV、Excel、Word、PDF 读写，图片与扫描件取字 |
| 图像与语音 | 读图、生图、改图、缩放裁切，语音合成与转写 |
| 桌面与浏览器 | 截图判断界面并操作应用，内置浏览器开页 |
| 远程与协作 | SSH 远程操作、查看仓库状态、并行拆分子任务 |
| 记忆与知识库 | 长期偏好与本地文档沉淀，语义检索召回 |

工具**按需加载**：默认只带常用的一批，任务需要时再启用，避免几十个选项分散注意力。

另有 **22 个内置技能**（代码生成与审查、Bug 修复、重构、测试、文档撰写、数据分析、翻译转换、Office 文档、会议纪要等），识别到场景自动激活，也可以直接点名使用。需要额外能力，可接入 MCP 插件或自定义技能。

## 安全与隐私

| 项目 | 说明 |
|------|------|
| 数据存放 | 配置、会话、技能与知识库保存在本机数据目录，换机器复制该目录即可迁移 |
| 出网范围 | 只有发给所选模型的请求会离开电脑 |
| 密钥 | API Key 在本机用系统加密能力存储 |
| 权限 | 四层权限模式，写文件与执行命令默认先确认 |

### 四种权限模式

| 模式 | 行为 | 建议 |
|------|------|------|
| 常规（默认） | 只读自动执行，写入与命令需确认 | 日常使用 |
| 严格 | 每一步都确认 | 陌生项目、生产目录 |
| 自动 | 全自动执行，危险命令仍被拦截 | 可回滚、可复核的任务 |
| 完全放行 | 全部放行，不弹确认 | 一次性沙箱环境 |
