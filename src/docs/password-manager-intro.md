# 记得 · 密码管理器 — 产品介绍

> 零信任架构：主密码从不离开你的设备。

---

## 产品概述

**记得·密码管理器** 是一款零信任架构的密码管理工具。所有敏感数据在客户端完成 AES-256-GCM 加密后才传输，服务端只保存密文——**它拿不到你的主密码，也打不开你的保险库**。

登录采用 OPAQUE 协议（RFC 9807）：主密码从来没有离开过设备，服务端连低熵的口令派生值都接触不到。

产品覆盖 **Web 管理端**、**Chrome 浏览器扩展**、**AI 助手接入（MCP）** 三种使用方式，日常管理、自动填充、安全审计各有对应入口。

## 为什么值得信任

| 环节 | 做法 | 对你意味着什么 |
|------|------|----------------|
| 登录 | OPAQUE（RFC 9807）密钥协商 | 主密码不出设备，服务端连口令派生值都拿不到 |
| 保险库数据 | AES-256-GCM，密钥由主密码经 PBKDF2-SHA256（600,000 次）派生 | 服务端只有密文，没有主密码就打不开 |
| 传输 | AES-256-GCM，密钥由登录会话密钥派生 | 全链路加密，中途截获也解不开 |
| 会话 | JWT Bearer，不下发 Cookie | 少一类 CSRF 攻击面 |
| 二次验证 | TOTP（RFC 6238） | 密码之外多一道动态验证码 |
| 账号标识 | 对外 ID 加密为 `eid:xxx` | 无法通过编号枚举他人账号 |
| 撞库防护 | 连续 5 次失败锁定 15 分钟 | 猜到密码的成本高到不划算 |
| 泄露检测 | HIBP k-匿名模型，只发送 SHA-1 前 5 位 | 能知道密码是否已泄露，又不上传密码本身 |
| 内容安全 | 服务端清洗与过滤 | 降低跨站脚本风险 |

## 核心功能

### 🔐 端到端加密存储
数据在浏览器端加密后才上传，服务端零明文保存。即便数据库被拿走，得到的也只是密文。

### 🔑 主密码不出设备
登录走 OPAQUE 协议，主密码与口令派生值都留在本机；换设备需要重新验证，不走「把密码发给服务器比对」的老路。

### ✨ 密码生成器
按长度与字符类型生成高强度随机密码，生成即存，不用自己编、也不用在多个网站重复用同一个。

### 📁 文件夹管理
树形目录自由分类，工作、生活、财务各归其位，条目多起来也不用逐个翻找。

### 📱 TOTP 二次验证
内置一次性验证码生成，扫码即绑定，不必再装额外的验证器 App。

### 💓 健康与泄露检测
扫描弱密码、重复密码与已泄露密码，给出安全评分和改进建议。泄露检测以 k-匿名方式核对，密码本身不出设备。

### ⚡ Chrome 自动填充
配套浏览器扩展，登录时一键填写账号密码，告别手动输入与复制粘贴。

### 📤 加密导入导出
支持加密格式导出备份，换设备、换工具都能带走自己的数据。

### 🤖 AI 助手接入
提供 MCP 服务，AI 助手可以代为查询、取用账号完成登录类任务；账号密码统一存放在本机加密文件里，不写进配置文件。

## 技术架构

| 部分 | 技术 |
|------|------|
| Web 管理端 | Vue 3 + Vite + Element Plus |
| 后端服务 | Spring Boot 3.5 / Java 21 |
| 数据库 | PostgreSQL（仅存密文） |
| 浏览器扩展 | Chrome Manifest V3 |
| 登录与会话 | OPAQUE（RFC 9807）+ JWT |
| 加密算法 | AES-256-GCM、PBKDF2-SHA256、HKDF-SHA256 |

## 开始使用

- **官网地址**：[https://pwd.regaing.com](https://pwd.regaing.com)

注册后设置主密码即可使用。主密码是打开保险库的唯一凭证，**丢失后无法找回**，请务必单独妥善保管。

### AI 助手接入（可选）

在支持 MCP 的 AI 助手配置中加入：

```json
{
  "mcpServers": {
    "credential-vault-mcp": { "command": "npx", "args": ["-y", "credential-vault-mcp"] }
  }
}
```

账号密码统一存放在本机加密文件 `~/.mcp-store/data.bin`，不写在配置文件里。
