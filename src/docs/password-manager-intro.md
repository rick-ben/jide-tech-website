# 密码管理器 - 产品介绍

> 安全、高效的企业级密码管理方案，端到端加密守护您的数字身份。

---

## 产品概述

**记得·密码管理器** 是一款全功能密码管理工具，专注于为个人和企业用户提供安全可靠的密码存储与管理服务。采用零信任端到端加密架构，确保您的数据只有您自己能访问。

产品涵盖 **Web 管理端**、**浏览器扩展** 两大核心形态，覆盖日常密码管理、自动填充、健康检测等全场景需求。

## 核心功能

### 🔐 端到端加密
采用 AES-256 加密算法，从浏览器端加密后传输至服务器，服务端零明文存储。结合 Argon2id 密码哈希算法，构建多层安全防线。

### 🔑 密码生成器
智能生成高强度随机密码，支持自定义长度、字符类型（大小写字母、数字、特殊符号），一键生成即存。

### 📁 文件夹管理
树形目录结构，支持自由创建多级文件夹，按工作、生活、财务等场景分类管理密码，查找效率倍增。

### 📱 TOTP 双因素认证
内置一次性验证码生成器，扫码即可绑定账户，告别安装额外验证器 App 的繁琐。

### 💓 密码健康检测
自动扫描检测弱密码、重复密码和过期密码，提供安全评分和针对性改进建议，持续提升账户安全性。

### 📤 数据导入导出
支持加密 JSON 格式一键导出备份，随时迁移数据至其他设备。数据掌控权完全在您手中。

### 🌐 跨平台访问
响应式 Web 设计，支持桌面端、平板、手机等多种设备访问，随时随地管理密码。

### ⚡ 浏览器自动填充
配套 Chrome 浏览器扩展，登录网站时一键自动填写账号密码，告别繁琐手动输入。
